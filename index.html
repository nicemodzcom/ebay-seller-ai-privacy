eBay Seller AI

Privacy Policy

Last updated: October 20, 2026 · Privacy enquiries: support@nicemodz.com

Development notice. eBay Seller AI is currently a personal application project under development. This page describes the proposed functionality and privacy principles. Before connecting live seller accounts, we will update it to identify the data controller fully, document the actual data flows, service providers, legal bases and retention periods.

1. About eBay Seller AI

eBay Seller AI is an independent project intended to assist with preparing and managing eBay listings. It is not operated, sponsored, or endorsed by eBay Inc. For enquiries relating to this project, email support@nicemodz.com.

2. Planned use of personal information

Once the integration is implemented and authorised by the user, it may process only information necessary for requested features, including:

  • eBay account identifiers and authentication authorisations;
  • item photographs, descriptions, categories, prices, and listing statuses;
  • order and shipping details required to review or fulfil a sale, where explicitly enabled;
  • technical records needed for the application's security and operation.

Additional data sources and processing activities, if introduced, will be disclosed here before they are activated.

3. Why information is processed

The intended purposes are to prepare listing drafts, publish or update listings on the user's instruction, manage authorised inventory and order tasks, secure connections, and respond to enquiries. The lawful bases required by applicable privacy laws will be specified once the actual service design and data controller are finalised.

4. eBay access and authorisation

The planned integration uses eBay's official OAuth authorisation process. Users will sign in on eBay's pages and approve requested permissions there. We do not ask users to enter their eBay password on this privacy-policy website. API credentials or OAuth tokens must never be placed in publicly accessible GitHub Pages files.

5. Sharing and service providers

Authorised features will communicate with eBay's APIs. Any additional cloud hosting, AI processing providers, external processors, or international data transfers will be identified and evaluated before the application processes live account information. This static information page is hosted by GitHub Pages, which may collect ordinary technical access information under GitHub's policies.

6. Data security and retention

The intended design restricts access to necessary information, stores confidential credentials only in protected environments, and removes personal information when it is no longer required. Specific storage locations, retention periods, and deletion procedures must be finalised and disclosed prior to production use.

7. Privacy rights

Depending on applicable law, individuals may request access to or correction or deletion of personal data, object to or restrict processing, or contact an applicable data-protection authority. Send privacy enquiries to support@nicemodz.com.

8. Cookies and analytics on this page

This page is static. It does not include third-party advertising, application analytics, or intentional tracking cookies. GitHub Pages may process routine technical visit data as described in GitHub's own privacy documentation.

9. Changes

This policy will be updated as the application develops. Material changes will be reflected in the updated date above. The current development notice should not be treated as a final privacy notice for an operational service.
